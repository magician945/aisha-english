# Sprint 1 · 首周冲刺计划（M0 第 1 周）

> 依据：《产品与技术架构方案 V0.3》06 章路线图与 08 章待拍板项。
> 目标：跑通「PWA 真机四项验收 + 字母港原型可玩 + 内容自动扩词管线试运行」。

## 每日拆解

| 天 | 任务 | 产出 / 验收 |
|---|---|---|
| D1 | 仓库与流水线接入 GitHub 账号；体验版部署 | push 即发布；`https://<user>.github.io/<repo>/` 可访问 |
| D1–D2 | **nova 14 Ultra 真机四项实测（P0）** | 自检页四项通过；不达标项出调优结论（兜底：微信小程序评估） |
| D2–D3 | 字母港原型打磨：音色、手感、动画、字体 | 真机完整玩 3 轮无卡顿；断网可玩 |
| D3–D4 | 教研逐课脚本模板（CEFR Pre-A1 对齐 + 音形义三通道字段） | Lesson 1–3 脚本进入课程引擎 JSON |
| D4 | AI 词句工坊试运行：LLM 模板 → 机审 → 教研人审 → 热更 | 每周扩词 5–10 个的流水线打通（M0 试运行） |
| D5 | 埋点事件表 + 家长周报字段冻结 | `app_start / lesson_start / lesson_complete / speak_score / block_earned / build_place / parent_report_open` 口径定稿 |

## 验收清单（周会逐条勾）

- [ ] GitHub Actions 自动部署绿勾
- [ ] nova 14 Ultra 四项 P0 全通过（或调优结论明确）
- [ ] 字母港 Lesson 1 真机完整通关 ×3
- [ ] 离线模式（飞行模式）可完整游玩
- [ ] Lesson 2/3 脚本入库，课程引擎热更生效（不发版换课）
- [ ] AI 词句工坊产出第一批 5 个词卡并通过双审

## 依赖与风险

| 依赖/风险 | 对策 |
|---|---|
| GitHub 账号授权（用户侧） | 用户登录 GitHub 建仓库后提供仓库地址；流水线已就绪 |
| 鸿蒙浏览器 WebGL / 麦克风 / SW 表现未知 | D1–D2 真机实测前置；不达标先调优，兜底微信小程序（鸿蒙版） |
| TTS 音色不适合儿童 | 体验版接受；正式版外教录音 + TTS 混合（方案 4.4） |
| github.io 国内可达性 | 体验版不承诺；正式版切国内 CDN（备案域名） |
